# 通用性与证据判定修复

用户授权：2026-11-11，依据最新代码审查纠偏开发。

目标：通用扫描不隐含 Juice Shop 账号、路由、种子数据；专用适配显式选择。保留历史任务记录，不把回放改成新扫描。

实施顺序：

1. 新任务采用 v7 / generic 默认；v1–v6 保留历史兼容。Juice Shop 探针隔离为适配器，仅显式选择后生成；普通目标不自动注册账号或猜测试账号。
2. 加入通用双身份资源访问验证：操作者声明两个凭据档案、各自资源、身份字段及私有访问策略；执行本人基线、交叉访问、匿名对照。全部精确请求进入审批，无种子编号。
3. 浏览器探测使用唯一标记、无载荷对照与重复验证；网络经现有受控 HTTP broker 转发，禁用 Service Worker/WebSocket，失败保守计费。通用目标由实际路由生成探针。
4. 离线评估区分候选/行为/漏洞确认；专用映射校验目标与精确接口，禁止把任意 SQL 错误映射搜索注入。保留既有分母，分类不确定显式显示，不因探针失败调整分母。
5. 回归含改名路由、不同 JSON 字段、两个身份、公开资源、修复版阴性、浏览器正常弹窗；运行工作台相关与全量离线测试。跨靶场真实扫描和模型验收没有实际执行前不声称通过。

交付：代码、测试、UI 配置说明与 STATUS/handoff。通用账号的自动注册/登录发现仍不能凭接口名称猜测；支持用户已有 Cookie/Bearer 凭据。测试通过不等于未知应用覆盖率保证。
