## 启动

```powershell
# 项目目录
.\.venv\Scripts\python.exe -m vulnmind doctor     # 期望除 model_key 外全部 ok
.\start-workbench-background.cmd                   # 后台常驻，打开 http://127.0.0.1:8765
```

- 模型模式：需要 `DEEPSEEK_API_KEY`；没有时不要勾选"启用模型规划"。
- 浏览器复核：`.\.venv\Scripts\python.exe -m pip install "playwright>=1.40,<2"`，需要本机 Edge。
- 数据库：`0019_durable_step_failed`，`doctor` 已验证审计链 97,892 条有效。

1. `doctor` 的 `model_key` 取决于启动服务的用户环境；本 shell 未设置时显示 warn。
2. 恢复时每个已完成阶段会重算审计链，阶段多的任务恢复需要数分钟。
3. UI 不直接展示覆盖率百分比；覆盖率由离线脚本 `scripts/juice_shop_coverage_report.py` 生成。
